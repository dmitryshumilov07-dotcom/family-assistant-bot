# 🔧 Диагностика Family Assistant Bot

Полное руководство по диагностике и мониторингу семейного ассистента.

## 📋 Доступные инструменты

### 1. **diagnostics.py** - Полная диагностика
Комплексная проверка всех систем бота.

```bash
python3 diagnostics.py
```

**Что проверяется:**
- ✅ Переменные окружения (BOT_TOKEN, DEEPSEEK_API_KEY)
- ✅ Наличие необходимых файлов
- ✅ Состояние базы данных
- ✅ Установленные Python пакеты
- ✅ Права доступа
- ✅ Подключение к Telegram API
- ✅ Подключение к DeepSeek API

**Результат:** Создает детальный JSON отчет с результатами всех проверок.

---

### 2. **monitor.py** - Мониторинг в реальном времени
Отображение текущего статуса бота.

```bash
python3 monitor.py
```

**Что показывает:**
- 🔐 Статус переменных окружения
- 💾 Состояние базы данных
- 👥 Статистика пользователей
- 🛒 Список покупок
- 📁 Наличие файлов проекта
- 📊 Результаты последней диагностики
- 🚦 Общий статус системы

---

### 3. **health_check.py** - Быстрая проверка здоровья
Легковесная проверка для автоматизированного мониторинга.

```bash
python3 health_check.py
echo $?  # 0 = здоров, 1 = нездоров
```

**Использование в cron:**
```bash
*/5 * * * * /usr/bin/python3 /path/to/health_check.py || /path/to/alert.sh
```

---

### 4. **init_database.py** - Инициализация базы данных
Создание/пересоздание базы данных с начальной структурой.

```bash
python3 init_database.py
```

**Что создает:**
- Структуру БД с пользователями (Ирина, Дмитрий)
- Пустой список покупок
- Историю чатов для каждого пользователя

## 🔍 Типичные проблемы и решения

### ❌ Проблема: "BOT_TOKEN не установлен"

**Причина:** Отсутствует переменная окружения с токеном Telegram бота.

**Решение:**
```bash
# Создайте/обновите файл .env
echo "BOT_TOKEN=ваш_токен_здесь" > .env
echo "DEEPSEEK_API_KEY=ваш_ключ_здесь" >> .env
```

---

### ❌ Проблема: "DeepSeek API ключ недействителен"

**Причина:** API ключ неверный или истек срок действия.

**Решение:**
1. Проверьте ключ на https://platform.deepseek.com
2. Получите новый API ключ
3. Обновите в `.env`:
   ```bash
   DEEPSEEK_API_KEY=новый_ключ
   ```

**Тестирование ключа:**
```bash
python3 test_deepseek_key.py
```

---

### ⚠️ Проблема: "База данных не найдена"

**Причина:** Файл `family_data.json` отсутствует.

**Решение:**
```bash
python3 init_database.py
```

---

### ⚠️ Проблема: "База данных повреждена"

**Причина:** Невалидный JSON в файле БД.

**Решение:**
```bash
# Создайте резервную копию
cp family_data.json family_data.json.backup

# Пересоздайте базу
python3 init_database.py
```

---

### ❌ Проблема: "Пакет не установлен"

**Причина:** Не установлены зависимости Python.

**Решение:**
```bash
pip3 install -r requirements.txt
```

## 📊 Интерпретация результатов мониторинга

### 🚦 Статусы системы

#### ✅ РАБОТОСПОСОБЕН
Все системы функционируют нормально. Бот готов к работе.

**Критерии:**
- ✅ Все токены установлены
- ✅ База данных существует и валидна
- ✅ Все файлы на месте
- ✅ API доступны

#### ⚠️ ЧАСТИЧНО РАБОТОСПОСОБЕН
Есть некритичные ошибки. Бот может работать с ограничениями.

**Возможные причины:**
- ⚠️ Проблемы с DeepSeek API (бот будет отвечать ошибками на запросы)
- ⚠️ Низкий размер базы данных

#### ❌ ТРЕБУЕТСЯ НАСТРОЙКА
Критичные ошибки. Бот не может работать.

**Возможные причины:**
- ❌ Отсутствуют токены
- ❌ Нет базы данных
- ❌ Отсутствуют файлы

## 🔄 Процедура диагностики при проблемах

### Шаг 1: Запустите полную диагностику
```bash
python3 diagnostics.py
```

### Шаг 2: Проверьте отчет
```bash
ls -lt diagnostic_report_*.json | head -1
cat diagnostic_report_*.json | python3 -m json.tool
```

### Шаг 3: Проверьте текущий статус
```bash
python3 monitor.py
```

### Шаг 4: Устраните найденные проблемы
Следуйте рекомендациям из отчета.

### Шаг 5: Повторите диагностику
```bash
python3 diagnostics.py
```

## 📈 Автоматический мониторинг

### Настройка cron для периодических проверок

```bash
# Редактировать crontab
crontab -e

# Добавить строки:
# Полная диагностика каждые 6 часов
0 */6 * * * cd /workspace && python3 diagnostics.py

# Мониторинг каждый час и сохранение в лог
0 * * * * cd /workspace && python3 monitor.py >> /tmp/bot_monitor.log 2>&1

# Быстрая проверка каждые 5 минут
*/5 * * * * cd /workspace && python3 health_check.py || echo "Bot unhealthy" | mail -s "Alert" admin@example.com
```

## 🆘 Получение помощи

Если проблема не решается:

1. Проверьте логи бота
2. Запустите `python3 diagnostics.py` и сохраните отчет
3. Проверьте переменные окружения: `env | grep -E "BOT_TOKEN|DEEPSEEK"`
4. Проверьте права доступа: `ls -la family_data.json`
