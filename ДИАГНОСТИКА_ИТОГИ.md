## ❌ КРИТИЧЕСКИЕ ПРОБЛЕМЫ

### 1. ❌ DeepSeek API ключ недействителен

**Детали:**
- HTTP Status: 401 (Unauthorized)
- API Key начинается с: `sk-6810fa6...`
- Ошибка: Неверный или истекший API ключ

**Воздействие:**
- 🔴 Бот НЕ МОЖЕТ генерировать AI ответы
- 🔴 Все сообщения пользователей будут возвращать ошибку
- 🟢 Остальные функции (команды /start, /add, /shopping) работают

**Решение:**
1. Зайти на https://platform.deepseek.com
2. Проверить текущий ключ или создать новый
3. Обновить в `.env` файле:
   ```bash
   DEEPSEEK_API_KEY=новый_ключ_здесь
   ```
4. Перезапустить бота

Для постоянного мониторинга агента созданы следующие инструменты:

### 1. `diagnostics.py`
Полная комплексная диагностика всех систем.
```bash
python3 diagnostics.py
```
- Проверяет 17+ параметров
- Создает JSON отчет
- Время выполнения: ~5-10 секунд

### 2. `monitor.py`
Мониторинг в реальном времени с детальной статистикой.
```bash
python3 monitor.py
```
- Показывает состояние всех компонентов
- Статистика пользователей
- Состояние API
- Время выполнения: <1 секунда

### 3. `health_check.py`
Быстрая проверка для автоматизации.
```bash
python3 health_check.py
```
- Возвращает 0 если здоров, 1 если нет
- Идеально для cron/systemd
- Время выполнения: <1 секунда

### 4. `init_database.py`
Инициализация/пересоздание базы данных.
```bash
python3 init_database.py
```
- Создает структуру БД
- Добавляет пользователей
- Безопасно (спрашивает перед перезаписью)

### 5. `test_deepseek_key.py`
Проверка валидности DeepSeek API ключа.
```bash
python3 test_deepseek_key.py
```
- Тестирует реальный запрос к API
- Показывает детальную ошибку
- Предлагает решения
