## 📈 РЕКОМЕНДАЦИИ ПО МОНИТОРИНГУ

### Настройка автоматического мониторинга

#### 1. Cron для периодических проверок

```bash
# Редактировать crontab
crontab -e

# Добавить задачи:

# Быстрая проверка каждые 5 минут
*/5 * * * * cd /workspace && python3 health_check.py || echo "Bot down" | mail admin@example.com

# Полная диагностика каждые 6 часов
0 */6 * * * cd /workspace && python3 diagnostics.py

# Мониторинг каждый час
0 * * * * cd /workspace && python3 monitor.py >> /var/log/bot_monitor.log
```

#### 2. Systemd service (опционально)

Создать `/etc/systemd/system/family-bot.service`:

```ini
[Unit]
Description=Family Assistant Bot
After=network.target

[Service]
Type=simple
User=ubuntu
WorkingDirectory=/workspace
ExecStart=/usr/bin/python3 /workspace/bot.py
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
```

Активация:
```bash
sudo systemctl enable family-bot
sudo systemctl start family-bot
sudo systemctl status family-bot
```
